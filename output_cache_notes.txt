To monitor whether or not a GET request returns a cached response or not, the Products API controller result DTO has a property of "FetchedTime" that is 
populated with the current server time by the controller when the response is generated by the controller action.  If the response is served from cache, 
the controller action will not run, and the property will not be updated and this time will be earlier than the current time.  Dointg it this way avoids 
setting a property on the actual entity as it is outside of the scope of the domain, and also avoids having to modify services and objects used by the controller.
